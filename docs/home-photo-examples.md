# ホームの写真とコマ表示例（P3-12b）

ホームのスマホ3枚は、固定の三崎ルートから生成した確認可能なコマを選んで掲載する。自動切替/スワイプを維持し、表示順を `data/ui/home-examples.json` に分離した。公開コース・下書き・DBは参照しない。

## 3枚を選ぶ

1. `npm run home:gallery`（PowerShellでは `npm.cmd run home:gallery`）を実行する。
2. 出力された `.local-data/home-koma-gallery.html` をブラウザで開く。
3. 選択済みの候補を外し、好きな候補を3枚選ぶ。選んだ順がスマホの表示順となる。初期状態の2/3/4は以前のまま。
4. 「設定JSONをダウンロード」で取得し、`data/ui/home-examples.json` を置き換える。番号を開発担当へ伝えて変更してもよい。
5. 開発画面を再読込みする。本番配信用は再ビルドする。

一覧は26候補の全枝・元の点列・進入方向・出発矢印を使った形状比較で、テーマ装飾/交通目印は省く。掲載時は通常の共通描画部品で目印も描く。番号はこの固定道路データのコマ番号で、同じ交差点の逆方向も別候補。3枚は連続しなくてもよく、実際の連続案内とは扱わない。候補外/重複/3枚以外は生成エラーにして別地点へ黙って差し替えない。

生成HTMLはローカルだけに出力し、アプリへ選択用画面・保存APIは追加しない。ダウンロードしてもリポジトリを直接変更しない。設定ファイルだけがビルド入力で、AWSへも同梱できる。

## 写真と対応するコマ

指定座標（35.14143652320008, 139.61838070052278）から約5.94mのOSM node/2159253432（35.1413926, 139.6183435）を採用した。`introductionSequence: 5` は既存三崎ルートの同じ交差点で、形状や進行方向を捏造せず元の図をそのまま用いる。写真撮影位置とOSM交差点のずれは残る。写真のカメラ方位・撮影時期までの一致や現地の通行は未確認。逆向きは候補27で確認できる。

「いつもの散歩が、ちいさな冒険に。」の路地写真には、この独立したコマを重ねる。スマホの1枚目を変えても路地写真側のコマは変えない。建物形状/名称を出さない現在の方針に合わせ、初期採用の交通目印と階段を扱う共通描画を使う。

## 追加写真の配置

ユーザー提供の「海へ続く道を示す旅人たち.png」を `public/mainphotos/walking-together.png` へ同一バイトで同梱した。元ファイルは保持し、人物の合成/背景除去や画像の再生成は行わない。既存の紹介写真とコマの間へ、角丸の写真を傾けて重ねる。CSSのトリミングで二人とスマホが見える位置に合わせ、新しいセクションやシーンの高さは追加しない。写真は体験イメージとして扱い、指定座標の実景とは扱わない。

## 検証・自己レビュー

- ホーム単体6件・型チェック・最終本番ビルドに成功。全体の単体スイートは今回は再実行していない。
- 開発/本番の両方で操作前後のHTTP検査各34件に成功。写真4点は配信バイトのSHAが元と一致した。
- 320/390/768/1440pxで横はみ出しなし。紹介シーンの高さは既存の420/445/470/510pxを維持し、新しいセクションを追加していない。PCでも追加写真の二人・手元のスマホが見えるよう配置を調整した。
- 3コマの前後/番号/左右キー/実タッチのスワイプ、5秒自動切替/停止/再開、動きを減らす設定を確認した。元の3枚と紹介コマの枝ID/全点列は生成元と一致した。
- 候補一覧の全26枚の枝ID/点列を照合し、4枚目の拒否・3枚未満での出力不可・選択順を確認。27→6→5の順に選択してダウンロード処理へ渡ったJSONを読み戻し、その順でコマを生成できた。紹介用設定は維持された。
- ホームで運営/公開コースAPIへの要求なし。Runtime/console例外0件。通常参加者UI・自動生成/保存処理・依存ロック・環境変数は変更していない。
- 実DB・元の写真・道路/スポット/地域索引・mainの指紋を保持。ルート直下の提供PNGは変更/削除せず保持し、配信用コピーだけをGit対象にする。

自己レビューでは、掲載例の選択とコース生成を分離し、道路形状を変えず、写真側のコマとスマホの3枚が独立すること、CSSが既存の紹介枠内だけへ作用すること、画像の出典/バイト一致と秘密情報の除外を確認した。検証側は既存の320px専用高さにも合わせた。実機/現地・写真の撮影方位/時期の一致・AWSは未確認。コミット後に停止する。

## 次に用意すると伝わりやすい写真（提案）
