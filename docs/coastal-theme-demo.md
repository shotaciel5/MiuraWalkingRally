# 海の青を使う配色と、冒頭の3コマ体験

- 日付：2026-11-11
- 状態：ユーザーが配色と改善1/2/3・写真の可能な範囲での収集を明示採用。実装・検証済み、レビュー待ち。

## 今回の範囲

深い青 #174B66、アイボリー #FAF7F0、淡い水色 #DDEEF1、朱色 #BF523B、本文の墨色 #203744 を採用。色の役割を分け、見出し/地図は青、主要操作は朱色にする。参加者/運営者/旧デモとコマの配色・矢印の説明をそろえる。標識やジャンル記号は意味のある色を保つ。図形/道路接続/距離/訪問順・保存形式を変更しない。

冒頭の写真にスマホ型の3コマ体験を重ね、実際の固定道路データから生成した連続3コマを使う。5秒ごとに横へ切替え、最後から最初も連続するよう複製スライドでつなぐ。スワイプ・前後・番号選択、矢印キー、停止/再生を用意する。操作/フォーカス/マウスが入ると停止。範囲外/タブ非表示では進めず、動きを減らす設定では初期停止/切替の動きを抑える。開始記録/公開コースとは独立した表示例で、現地到着を判定しない。

3ステップに線画アイコンを加え、運営者向けに「地点を選ぶ→道路沿いルート→コマを確認/公開」の図を追加する。ルートとコマの図は既存生成器の固定結果を使い、生成AIの画像ではない。現地確認は継続して必要。新規依存/外部CDN/フォント・自動外部通信・DB/APIを加えない。

## 写真

[収集記録](photo-candidates.md)を参照。三崎朝市と商店街の利用条件は個別説明で確認できたが、取得先がHTTP 429を返したため再試行/代替経路での回避は行わない。県のライブラリーは利用フォーム/成果品URL通知等があり、第三者への連絡は実施しない。写真の追加は行わず、提供済み3点を継続する。人物のスマホ利用風景や実際の分岐との対応写真は、ユーザーによる後日の収集候補。

## 自己レビューと停止

承認された配色と改善1/2/3を今回の範囲とし、写真の追加を完了したと扱わない。UIの図は実際の固定道路/既存生成器に基づき、手描きや生成AIで枝を補わない。ルート/コマの計算・元の角度/全枝/距離・短い枝の拡大計算、既存の保存/公開/参加の形式とCP名の表示条件を維持する。図の確認待ち/現地未確認は表示を続ける。

タイマー/Observer/メディア/可視状態の監視は画面終了時に解除し、写真/参加記録を送信しない。新しい保存・認証/クーポン・AWS/外部連絡は行わない。検証は隔離コピーと専用DBで行い、利用中の.nextや実DBを使わない。Git対象を確認し、元データ7件/提供写真3点・実DBのハッシュとmainを最終照合した。変更30ファイル・検証コピー内のソース20件の一致、元DB/道路/写真11件のハッシュ非変更と相対リンク285件の整合を確認した。既存CSS/KomaFigure/目印ラベルには、色と矢印の色名以外の変更がないことも照合した。

feature/coastal-theme-demoへコミットして停止し、見た目と操作を人間にレビューしてもらう。次の提案は、実機でのスワイプ/再生・停止と撮影への往復、人物の手元/同じ分岐の実景/立ち寄り写真の収集。自動で次の機能へ進まない。
