# PoC画面の撤去と初期スポット整理（P4-09）

2026-11-13。ユーザーの「アプリからPoCを取り除く」「スポットのデモをなくし、重複を整理して半分程度」という明示指示に基づく。

## アプリの入口

PoC専用の目印比較・サンプル採否・画像切り出し画面と、旧固定デモの詳細/開始/達成/終了のUIを撤去する。運営トップの検証リンク、台帳/下書きのデモ表示・全候補切替、削除確認の固定デモ専用説明を廃止する。トップの3コマによる遊び方の表示例はアプリ紹介として維持する。

| 旧URL | 現在の遷移先 |
| --- | --- |
| /poc | /operator |
| /operator/landmarks、/operator/landmarks/review（クエリ付きも同じ） | /operator/preview |
| /rallies/misaki-shitamachi、同 /play | /courses |

旧画面はサンプル情報を描画せず307で案内する。通常の選択中コマの目印採否・写真/階段・③による省略・保存/公開・参加者の撮影案内は継続する。目印APIは実際の下書きだけを返し、sample要求は400。外部取得は引き続き403、入力/Origin/保存競合の検証は維持する。

開発用のアルゴリズム、学習済みモデル、回帰テスト、取得バッチ・凍結資料と過去の報告は残す。保存済み・公開済みコースや既存のタブ内記録を削除/変更しない。開発CLIのdemo:seedは任意の検証用とし、通常起動の必須手順から外す。

## スポットの選定

初期候補は178→89件（50%）。三崎58・城ヶ島31、全13カテゴリと全6表示ジャンルを維持する。食・カフェ・土産・体験・宿泊・名所・海岸/展望・公園などを地理的に分けて残す。登録数は追加/編集や削除の保存状態により89件とは異なる。

- 海南神社（本土側）は代表のosm-way-384676338にまとめ、イチョウ2件・境内社・塚など10件を初期候補から除く。
- 城ヶ島灯台周辺の小地物、諸磯神明社周辺の小社、白秋碑と碑苑も訪問先として代表化する。計19小地物を4代表へ整理する。施設の同一性/境界の現地認定ではなく、初期候補の編集方針。
- 残る70件は近接した同種候補の密度と地域/ジャンル配分を見て初期候補から外す。すべてを重複や閉業と判定したものではない。
- 離れた同名の海南神社2施設は保持する。白秋記念館と碑苑など別の体験を提供する施設も区別する。近いという理由だけで個別店舗を自動統合しない。
- 選んだ元ID・名称・座標・出典・確認状態は変えず、新しい入口/徒歩接続や営業情報を作らない。

data/spots/curation.jsonに採用ID89件・除外IDと理由89件・代表対応・元カタログSHAを固定する。元のinitial-spots.jsonは178件の取得/監査資料として保持する。台帳と下書きは同じrepositoryで選定を適用するため、別画面の候補が食い違わない。

## 保存済みデータの扱い

元データ全体へ保存済み編集を重ねてから、選定済みか運営者の編集済み/追加済みかで抽出し、削除記録を適用する。選定から外れた元スポットに以前の編集があれば、それも保持して表示する。ユーザーが管理したデータを89件へ強制削除しない。起動時のDB書換え・移行・削除や新しい永続化方式は追加しない。

注入されたテスト/開発用カタログは独自の対象集合として扱い、既定の178件ソースにだけ本選定を適用する。旧元データの再現・道路検証を保つための既存loader境界を利用する。

保存/公開済み版の中のスポットや図はそのまま読む。未編集の除外スポットを使っている作業中下書きは、既存の「利用できない地点」表示で選び直しを求める。代表へ黙って置換せず、下書き/補正・保存済み版を自動変更しない。今回の実DBの下書きで使う海南神社・光念寺・本瑞寺・うらりは全て選定に残る。実DBの追加2件も維持する。
