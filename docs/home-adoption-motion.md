# 改善ホームの採用と生成フローの演出（P3-12d）

## AIの伝え方

実装中のAIは[ルール＋機械学習による追加保持](hybrid-koma-omission.md)。ルールが省略可能としたコマと後の図の比較に学習済みRandomForestを使い、条件に合う候補を追加で残す。ルールが残したコマをAIで削除したり、道路形状や最短ルートを生成AIで描いたりする機能ではない。

ホームは「AIで、コマの選別をサポート」「ルールと機械学習で、残すコマの判断をサポート」と表示する。新しいモデル/推論/外部AIサービスは追加しない。生成とAI補助の流れを事前に用意した図で示し、演出中に実生成/AI推論/DB保存はしない。既存のホーム3枚はユーザーが選んだ固定表示例で、機械学習の実行結果をその場で見せた扱いにしない。

## 演出と操作

約4.8秒を1周期として繰り返す。

- 約0〜0.9秒：5つの地点を順にタップする手元の記号・波紋・選択チェックを表示。
- 約1〜2.2秒：元のルート全点列に沿って青線を描く。
- 約2.1〜3.4秒：AI補助の表示を強め、元の3枚を順に出現させる。
- 完成状態を短く保ち、次の周期へ進む。道路やコマの元データは変えない。

「演出を停止」は完成状態の静止図へ戻す。「演出を再生」は先頭から再開する。表示領域から外れたとき、タブ非表示時は動かさない。OS/ブラウザの「動きを減らす」設定は静止状態を優先する。JavaScriptが動かない場合も全図/本文/実際の参加・運営リンクを表示する。演出の記号や動作は読み上げで逐次通知しない。
