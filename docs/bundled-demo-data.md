## 新しい環境で使う

READMEのNode/npmを用意し、プロジェクトルートで次を実行する。依存取得後のデモ表示/登録にはMapillaryトークン・AWS・外部接続は不要。

```powershell
npm.cmd ci
npm.cmd run demo:seed
npm.cmd run dev
```

- /courses：参加者が2コースを選択し、開始してコマを閲覧する。
- /operator/courses：同じ2件を運営者側で確認し、公開停止/再公開できる。
- /operator/draft → /operator/preview → 「このルートの目印を選ぶ（PoC）」：三崎の下書きで道路のコマと写真候補を確認する。
- /operator/landmarks/review：従来の固定サンプル。初期登録コマンドやDBを使わず同梱写真を確認できる。

スポット選択画面のOSM背景タイルは別途ネット接続が必要だが、上記の同梱画像/コマと参加者デモの表示にはMapillaryへの接続を必要としない。

コース未登録のまま通常起動しても、既存の空の一覧/下書きの挙動を保つ。初期登録は**明示コマンドのみ**で、起動/リクエスト/ビルドが勝手にコースを追加・公開しない。

`npm.cmd run demo:seed` は既存のSPOT_DB_PATHを尊重する。同じ入力は同じID/指紋になり、再実行で重複しない。既存IDと異なる内容が衝突すると全登録をロールバックする。既存コース/公開情報・停止状態、スポット編集/削除、下書き、到達点補正を上書きしない。既に同じ指紋のコースが別IDで保存されていれば、追加も公開変更もせず保持する。

下書きは未保存で補正も存在せず、関連スポットが初期状態のときだけ1件作る。台帳が変わっていれば下書き追加を見送り、戻り値のdraftにcatalog-changedを示す。変更前の情報を保存したデモコース2件は、他の保存版と同様に台帳変更で書き換えない。

## ファイルと保存境界

- [コース設定](../data/demo/courses.json)：固定ID・地点ID・訪問順・版/基準日時。SQLiteファイルを配布せず、既存の生成/検証処理で保存形式v1へ変換する。
- [画像/地物の公開マニフェスト](../public/landmarks/miura-v1/manifest.json)：フラットなJSON。画像ファイルは同じpublicディレクトリに置く。
- [素材の出典と利用条件](../public/landmarks/miura-v1/NOTICE.md)。
- [ローカル初期登録](../lib/demo/seed.ts)：既存のSQLite v7へトランザクションで登録。スキーマ変更なし。
- [同梱データ読取](../lib/landmarks/bundled.ts)と[キャッシュ保存](../lib/landmarks/storage.ts)：読み取り専用の同梱データと書き込み可能な取得結果を分ける。

同梱データはビルドへ含め、画像はNext.jsのpublic静的ファイルで配信する。画像名は元画像IDとハッシュを含む。画像APIは要求された元画像ID/処理版を検証してから同一アプリ内の静的画像へリダイレクトし、異なる画像を切り抜き範囲に当てない。

有効なローカルキャッシュを優先し、不在/期限切れの場合は同梱データを参照する。同梱素材に7日のキャッシュ期限は適用しない。元の取得日/撮影日を改変して新しく見せず、画面にも固定デモ素材である旨を表示する。破損したローカルキャッシュは従来どおりエラーとし、破損を隠さない。同梱データの閲覧だけで.local-dataへコピー/書込みしない。

新しいルートの未収録地点/写真は引き続きMAPILLARY_ACCESS_TOKENで取得し、LANDMARK_POC_DIRへ保存する。これらの取得結果とDBはGit対象外のままで、追加取得物が勝手に共有データになることはない。

## 出典と配布条件

2026-11-12確認：

- [Mapillaryの画像ライセンス説明](https://help.mapillary.com/hc/en-us/articles/115001770409-CC-BY-SA-license-for-open-data)と[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)に基づき、元画像/作者・ライセンスへのリンクと切り抜き/縮小を表示する。同梱画像と切り抜きの画像利用条件をアプリのソースコードへ一括適用するものではない。
- [Mapillaryの派生メタデータ説明](https://help.mapillary.com/hc/en-us/articles/115001777705-OpenStreetMap-compatibility)に従い、地物情報の同梱データベースを[ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/)として提供する。公開マニフェストに対象データ全体とライセンスURIを含め、画面からダウンロードできる。
- OSMの道路/スポットには既存の出典/ODbL表記を継続する。
- 詳細API規約ページは調査環境ではログイン画面で、一般運用の保持/更新条件を包括的に確認したものではない。今回の少数デモ素材の同梱から、無制限の保存/収集を認めたと解釈しない。

## AWS移行との関係

同梱JSONとpublic画像は読み取り専用の配布物で、AWS SDKや環境固有の絶対パスを持たない。将来も静的素材として配信でき、共有画像ストレージへ移す場合も原画像ID・ハッシュ・切り抜き・出典を引き継げる。取得結果の保存先変更は既存の保存境界で扱う。将来のためだけのS3実装や複数アダプタは追加していない。

[AWS公式のNext.js対応](https://docs.aws.amazon.com/amplify/latest/userguide/ssr-amplify-support.html)ではNext.js 15の静的ページ/APIルート等を掲載している。ただし、現在のNode 24/node:sqlite・ローカル書込み・実DB移行をAmplify上で保証するものではない。初期登録コマンドをクラウドビルドへ組み込まない。AWSでは保存先選定後に同じ宣言データを取り込む処理を用意し、配信・永続化を別途検証/承認する。
