## 実画面と素材

参加者の画面は、隔離したアプリ・専用QA DBで作成した「三崎のまち歩き」の実画面。キャラクターを含まないsiteテーマを使用し、元DBを変更しない方法で撮影した。参加者の体験フローは同じコースの04→09→33枚目を使い、コースカードの読込み完了も確認した。運営画面の背景タイルは検査時に模擬したため、資料では目印編集や公開状態を切り出して示している。

- 海景・路地写真：[ユーザー提供の既存素材](../../public/mainphotos/README.md)。体験の効果を実証する写真という扱いにはしない。
- コマ形状：OSM道路から生成した実データ。3枚目は[ホーム写真の対応例](../home-photo-examples.md)と同じ近傍交差点で、PowerPointの線・図形として描画した。
- 道路/地図：© OpenStreetMap contributors、[ODbL](https://www.openstreetmap.org/copyright)。
- 地物索引：Mapillary由来の情報。既存の[配布方針と出典](../region-landmarks.md)を継承する。
- 5枚目の看板写真：mura / Mapillary、2020-07-11。[原画像](https://www.mapillary.com/app/?pKey=1406211946378470)、[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)。検出領域を切り抜き・縮小。feature ID 1180221232451171 / image ID 1406211946378470。写真部分の条件を保持する。
- 上記写真の配布用切り抜き：public/landmarks/miura-v1/06b595b41ce387ee1ebd5f464c2bfcaa1fddaccc6374a92a9bcfb4b061e47fc5.png。PPTX内にも作者・日付・ライセンス・出典リンクを付けた。
- 実際に使った画像の一覧とSHA-256：[assets-used.json](assets-used.json)。画像を含む画面は保存版で、利用者の個人情報やAPIキーは含めない。

## 再生成

Python 3.12で確認。Webアプリの依存や設定は変更しない。初回にPython依存を入れる場合：

~~~text
python -m pip install -r docs/presentation/requirements.txt
~~~

リポジトリルートからPPTXと本文を生成する。必要なスクリーンショットと図形データはassetsへ凍結済みで、再撮影・AWS・Mapillaryトークンは不要。

~~~text
python docs/presentation/build_deck.py
~~~

PDF/全ページ画像は、Windowsのデスクトップ版Microsoft PowerPointで書き出す。デッキはドキュメントウィンドウなしで開き、資料だけを閉じる。別のプレゼンテーションが開かれていればアプリ全体は終了しない。

~~~text
python docs/presentation/render_deck.py
~~~

実レンダリングの画像と検査結果はGit対象外の.tools/presentation-previewへ出力する。PPTXを直接編集した内容は再生成で上書きされるため、編集済みファイルは別名で保存する。
