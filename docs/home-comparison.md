# ホーム改善案の目視比較（P3-12c）

ユーザー提供の提案に沿った改善案を実装し、採用前に現行と比較する。既存の `/` は変更せず、比較を見た人が採否を決める。採用・既定切替は今回行わない。

## 開く場所

- `/home-preview`：現行/改善案/並べて比較を切り替える。各画面は独立してスクロールできる。「通常幅」は各枠の幅、「スマホ幅」は390pxを上限とする。狭い画面の並列比較は縦に並ぶ。
- `/`：現行ホーム。既存のメインナビゲーションへ比較用入口を追加しない。
- `/home-preview/proposal`：改善案を単独で表示する。PCの大きな幅で比較したい場合は単独表示か別タブを使う。

比較画面の「別タブで開く」からも各ページを開ける。比較画面で設定を変えても採用状態・公開コース・参加記録は変更しない。双方の参加/運営リンクは既存の `/courses` / `/operator` へ進む。

## 改善案に反映したこと

1. HERO：既存の写真・コピー・ツナ之介・3コマ操作を維持し、スポットからルート/コマ地図を自動生成できることを一文で追加。主CTAを「コースを探す」、作成をテキストリンクへ変えた。スマホではCTAをコマ体験より前に配置する。
2. HOW IT WORKS：路地/写真/コマの紹介と3ステップを一つのセクションへ整理。写真に対応するnode/2159253432のコマと追加の体験写真を保持する。
3. AUTO GENERATION：スポットの入力・道路沿いルート・コマ出力を一続きに見せる。入力は固定三崎ルートの5地点、道順は同じ固定ルートの全点列、出力は現在設定されたホーム3枚の抜粋。事前生成例と明記し、生成操作や動画再生に見せかけない。
4. WHY IT MATTERS：既存の神社写真を使い、店舗/景色への寄り道と企画のしやすさを伝える。売上/滞在時間等の未検証効果を断定しない。
5. GET STARTED：参加と運営の入口をコンパクトに整理する。

自動生成の新しい操作デモや生成APIは作らない。アルゴリズム・保存/公開・認証・AWS・外部サービスは今回の対象外。変更は表示比較に限る。新しい依存/環境変数/写真の外部取得はない。
