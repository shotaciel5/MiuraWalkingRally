# ADR-008：運営用スポット地図にLeafletとOSM標準タイルを使う

- 日付：2026-11-08
- 状態：承認済み。ユーザーが「A：Leaflet＋OSMの背景地図（推奨）」を選択。
- 対象：P4-01bのローカル一覧・位置確認。ルート生成の道路データやAWSバックエンドは変更しない。
- 関連：[設計](../design.md)、[バックログ](../backlog.md#operator-first)、[運営画面の記録](../operator-app.md)

## 決定

Leaflet **1.9.4** とLeaflet.markercluster **1.5.3**をブラウザ内の地図表示に採用し、package-lock.jsonで固定する。型定義は@types/leaflet **1.9.22**、@types/leaflet.markercluster **1.5.6**。Leaflet公式が[安定版として示す1.9.4](https://leafletjs.com/reference-1.9.4.html)と、対応する[markerclusterの1.5.3](https://github.com/Leaflet/Leaflet.markercluster/tree/v1.5.3)を使用する。React用の追加ラッパーは導入しない。

地図はクライアントの描画時に読み込み、SSR/ビルド時にwindowへアクセスしない。スポットの読み込み・検証・絞り込みを地図SDKから分ける。固定データと一覧はローカルで提供し、背景だけhttps://tile.openstreetmap.org/{z}/{x}/{y}.pngからブラウザで取得する。ネット接続・配信状況により背景が使えない場合も一覧・詳細を維持し、再読込みを用意する。

外部通信なしの位置図も比較した。今回の候補全域を道路背景とともに拡大・移動して確認するため、ユーザー承認によりオンライン背景を採用した。有料サービス契約・APIキー・AWSは不要。公開タイルの利用は[OSMの運用方針](https://operations.osmfoundation.org/policies/tiles/)に従い、常時提供や将来の本番配信を保証する選定とは扱わない。

## 利用と検証の条件

帰属とODbLへのリンクを地図上/直下へ常時表示する。通常のブラウザUser-Agent、HTTPキャッシュ、Refererを使う。プロキシ、一括取得、先読み保存、オフライン配布や保存ボタンは作らない。表示範囲は三崎・城ヶ島周辺に限定し、通常の閲覧に必要なタイルだけを取得する。

公開サーバーへ自動テストの拡大/移動リクエストを送らない。ブラウザQAではページを開く前にタイル通信を捕捉し、成功/失敗の両方をモックする。実配信の背景画像の手動目視・可用性確認は別途必要。将来プロバイダーや配信方法を変える時は、用途・条件・費用を確認する。

初期表示は地域/ジャンルを選んだ24件とし、全178件への切替と絞り込みを用意する。クラスタは表示上のまとめ方で、候補データや元の座標・IDを統合しない。登録・編集・削除、コースへの追加、公開はそれぞれ後続タスクとする。
