# ADR-022: 階段は必須表示し、写真候補の準備をルート単位で再現する

- 日付: 2026-11-12
- 状態: ユーザー依頼に基づくPoC実装。通常公開/参加者への適用は後続
- 根拠: 階段を必須にし、Mapillaryの切り抜き写真を候補に載せ、新ルートでも再現できる方法を求めた指示

## 決定

階段は既存道路データの属性として専用PoCで常に描画する。選択型の目印とは別に扱い、採否や初期化で消さない。元の枝/点/進行方向と保留条件を維持し、ハッチングで実際の段数や未記録の階段を補作しない。

ルート上の未取得地点と、位置/検出領域がある看板等の少数写真を共通の準備手順で取得する。ブラウザとCLIで同じ対象選別/再利用/失敗制御を使い、検証用のスポット/画像IDに処理を依存させない。写真は初期不採用で、作者/撮影日/出典・ライセンスと対応コマを一覧表示して運営者が判断する。

1回20地点の準備は次の未取得地点から続行できる。CLIには明示的な1〜200地点の上限を設け、地点の総キャッシュを200件までとする。品質条件に合う画像なしも24時間再利用して連続した無駄な取得を防ぎ、通信失敗とは区別する。永続ジョブ基盤・新しいモデル/SDK/クラウドサービスは追加しない。

## 影響と未解決

ADR-021のローカル保存/トークン保護・通常公開版を変更しない境界を継続する。Mapillaryのカバレッジ/現況・向き/位置・任意モニュメントの認識は保証しない。外部データ/入力/処理版が変わった後の同一結果を保証せず、保持/一般配信と採用素材/出典の保存版統合は後続。
