# ADR-025：道なり省略を標準表示とし、全候補を固定保存する

- 日付：2026-11-12
- 状態：ユーザーの統合依頼とUI方式の委任に基づく採用・レビュー待ち
- 仕様：[省略統合](../koma-omission-integration.md)

全候補・描画の生成を保ち、別の形状互換解析と反復選別で表示対象を決める。標準は引き継いだ現行ルールによる省略とし、設定ダイアログで全交差点へ一括切替する。手動の目印編集があるコマは保護する。

省略で図をCSS非表示にするだけでは番号/CP/距離/保存が食い違うため、共通の表示投影を運営者/参加者に使う。payload v3へ全候補・類似関係・必須保持理由・手動保護・表示対象/モードを固定し、旧v1/v2はそのまま読む。既存SQLite v7を使い、Pythonやクラウド依存は追加しない。

28mのWGS84枝と実経路の8m進入方向を使い、従来の30m描画は維持する。枝集合/通行制約の差・held/不明形状・必須地点は省略せず、相手形状が不明な類似比較も保持側へ倒す。元の直進信号の例外は条件を限定して保持する。

独立評価前のAI候補は資料と再現テストへ残す。今回のルール統合に旧再集計1.5%の精度を転用しない。保存済みの全候補を残す分だけ保存量は増えるが、版固定・再確認・旧コース保護を優先する。
