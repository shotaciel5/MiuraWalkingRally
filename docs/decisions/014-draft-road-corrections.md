# ADR-014：下書きごとに道路上の到達点を修正・保存する

- 日付：2026-11-09
- 状態：ユーザーがA案を承認。実装・検証済み。
- 対象：P4-04の最小修正範囲
- 関連：[ADR-013](013-saved-draft-preview.md)、[運営画面11節](../operator-app.md#p4-04)

## 決定

保存済み下書きに含まれるスポットの道路上到達点を、地図クリックまたは座標指定で選び直し、SQLiteへ保存して再生成する。施設の位置・訪問順を保持し、同じスポットの開始/終了/途中には同じ補正を使う。歩行禁止・保留の辺を許可へ変えず、現在許容する道路線分へ射影する。自動候補へ戻せるようにする。台帳・道路データの変更時は再確認し、修正後も現地未確認とする。コマの手描き編集・生成結果の保存/公開は後続。

## 保存と整合

既存SQLiteをv4へ移行し、1件の作業中下書きにrally_correctionsを追加する。v1/v2/v3のスポット編集・削除・下書きを保持し、移行失敗はトランザクションで戻す。補正は道路上候補とスポット版/施設位置・道路版を保持する入力条件で、生成した経路/コマや確認済みフラグは保存しない。

補正はスポットID単位。下書き名・順序/役割の変更は保持し、保存後の選択から外れたスポットの補正は同じトランザクションで除く。下書きの版とは別に補正版/保存日時を持つ。保存時は下書き版・補正版・スポット版・道路版を照合し、異なる変更で上書きしない。同じ内容の再試行は保存済みの版/時刻を使う。

候補計算POSTは保存せず、PUTで明示保存する。施設の位置は台帳から読み、クライアントから道路IDや許可フラグを受け取って採用しない。指定位置と候補との直線距離、施設と候補との直線距離を区別する。距離で安全性を判定する閾値は置かない。

## 表示と制約

/operator/connectionsへ下書き/生成画面から進み、対象スポットを選ぶ。保存・自動復帰後に/operator/previewで再生成する。道路版や台帳と一致しない補正は黙って再利用せず、確認/自動復帰を案内する。破損した補正や元道路と不整合な記録は初期化せずエラーとする。

修正は施設までの通路や入口の確認を意味しない。到達不能や保留図を必ず解消する機能ではなく、現在の道路データと歩行ルールを守る。現地検証・全域の道路/図形照合・追加の修正方式・生成結果保存/公開・AWSは後続。
