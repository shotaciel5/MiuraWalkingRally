# ADR-024：採用目印を保存コースへ固定し通常運営画面に統合する

- 状態：ユーザーの統合指示に基づく採用・レビュー待ち
- 日付：2026-11-12
- 関連：[P4-07の仕様・検証](../course-landmark-integration.md)、ADR-021〜023

## 背景

切り抜き候補の地域事前取得・静的配布と、画像のない固有物を候補から除くPoCは完了した。ユーザーは運営者システムの「選択中のコマ」への統合を依頼した。採否を保存しても通常の保存/公開版に反映されない状態を解消する必要がある。

## 決定

通常の生成プレビュー枠内に採否UIを置き、既存のルート別採用保存を使う。作業状態の明示保存後にコースを保存する。未保存状態でコースを保存できないようにし、サーバーでも採用状態・生成条件を照合する。

新規コースはpayload v2として採用地物・写真/出典・地域データ版を固定し、既存v1を移行せず読む。SQLiteのスキーマ/公開方式は維持する。保存/公開版は作業中の採用・台帳・地域索引を参照せず再表示する。画像はハッシュ付き同梱パスを保存し、配布更新で参照先を保持する。

運営者と参加者で共有描画を使い、階段必須・建物/名称省略と、元の道路形状/進行方向・拡大図/参照図を保つ。写真は初期不採用のまま。API取得や生成AI・追加クラウド依存は導入しない。

## 比較と影響

公開時に作業中の採用を参照すると過去のコースが変わるため採用しない。既存v1を一括更新すると承認済み/公開版を書き換えるため行わない。画像をDBへ複製する方式は現在の静的配布方針に不要。

採用保存とコース保存の2操作が必要だが、既存の競合・再送・不変保存を維持できる。写真を変えると別の保存版になり、旧画像の配布保持と出典の継承が必要になる。失効素材の対応・AWS永続化/配信は別タスクで判断する。
