# ADR-028：コース削除・保存後の下書き初期化と歩行時間

- 日付：2026-11-14
- 状態：承認済み。削除方式Bをユーザーが明示選択。

## 決定

保存済みコースは対象名/影響の確認後、公開停止と削除を1操作・1トランザクションで行う。開始済み参加者も次回読込みから閲覧不可とする。削除メタデータを保持し、アクティブな保存payload/公開行を除く。取消・競合・失敗時は削除しない。重複要求は同じ結果を返す。同じ内容は別IDで再保存できる。

コース保存成功と同じトランザクションで、一致する作業下書きと手動到達点補正を空にする。保存失敗や後から作った別の下書きは保持する。空状態をまたいでも版番号を単調増加させ、古い入力を取り違えない。

歩行時間は時速3kmに変更する。旧版も表示時に距離から計算し、保存済みの形状・payload・指紋を変更しない。同梱版の生成速度だけは互換性のため従来値を明示する。

## 理由と影響

運営者が次のコース作成を始めやすくし、不要コースを片付けられる。公開中は先に停止するA案と、停止/削除をまとめるB案を提示し、ユーザーがB案を承認した。復元UIは作らない。すでに開いている画面は再読込みまで残り得る。

既存SQLiteをv8へ追加移行し、削除記録と作業版の保持を加える。依存・クラウドSDK・外部通信は追加しない。ローカルDBのAWSへの置換は既存の未決定事項として残す。[詳細と検証](../course-lifecycle.md)。
