# ADR-013：保存済み下書きからの未確認プレビュー

- 日付：2026-11-09
- 状態：ユーザーがA案を承認。実装・検証済み・レビュー待ち。
- 対象：P4-03a
- 関連：[ADR-012](012-expanded-road-connections.md)、[運営画面](../operator-app.md#p4-03a)

## 決定

保存済み下書きから、各スポットの最寄りの未確認道路候補を一時的な到達点として生成する。下書きの訪問順を維持し、地点間を経路探索する。候補の事前採用ボタンは設けない。到達不能・全区間0mは生成を止め、理由と下書きへの導線を表示する。候補修正・生成結果の保存・公開は後続とする。

入力は現在のSQLiteから同じ読取トランザクションで取得した下書きと有効台帳。未保存の入力を生成に使わず、保存後に明示操作する。台帳の変更/削除が下書きと一致しない場合も止め、下書きで確認して再保存する。閲覧中の結果は元にした下書き版と保存日時を示し、再生成で最新の保存内容を読む。

/operator/previewはNodeサーバーで読み取り・生成し、結果を画面内に渡す。結果・確認済みフラグ・施設から道路への架空の通路をDBに保存しない。施設位置と道路候補、道路上距離と直線距離を区別する。途中の0m区間は役割と訪問列を保ち、全区間が0mのときだけ止める。

## 表示と実装詳細

全体地図は固定道路のSVGとして表示し、コマの位置と次のコマまでの経路、施設位置との参照点線を示す。全体/2/4/8倍を切替でき、拡大時は選択コマを中心に確認する。新しい地図サービスや外部取得は追加しない。

コマの結合処理を共通モジュールへ移し、既存の分岐・形状/角度・進入方向基準の描画を再利用する。全コマを一覧に残し、不明な形状は保留する。元の枝を省略/統合したり、曖昧な枝を推測して描いたりしない。拡張固定データの建物・目印/標識・道路名/階段は既存の上限/距離条件で表示する。道路途中の一時点はOSMノードと扱わず、元の道路へ出典リンクを出す。

## 残る確認

入口・施設までの通路・実際の通行/安全性は未確認。候補の修正、別接続グループ15件の個別調査、全域のコマ照合、生成結果の保存/公開・AWS配信は後続。プレビューを完成済みの公開コースとして扱わない。
