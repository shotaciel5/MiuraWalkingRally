# ADR-020：認証・特典を外し、写真撮影を促すコマ中心の参加者体験へ変更する

- 日付：2026-11-10
- 状態：ユーザーの明示指示で採用。P3-09として実装・検証済み。
- 基準：[要件v0.3](../requirements.md)、[参加者画面11節](../participant-app.md#photo-walk)、[バックログ](../backlog.md#photo-walk-task)。

## 方針変更

QR認証・AI写真認証・クーポン/特典は要件から撤回する。後続の保留機能として扱わない。参加者にはチェックポイントのコマで施設名と撮影を案内し、各自のスマホのカメラで撮った写真をゴールで見せてもらう。アプリはカメラを起動せず、画像のアップロード/保存・判定・撮影枚数/順序によるロックを設けない。競技としての得点/不正防止やGPS到着判定も行わない。

ゴールの最後のコマでは写真提示を案内する。コマを表示しただけで実際の到着・撮影/受付を認定せず、達成/終了記録を自動保存しない。写真を見せる具体的な相手/受付場所・時間は現地運用として未決定。

## 参加者の画面

一覧のカード構成・概算・チェックポイント数を維持し、開始ボタンから直接コマへ進む。公開中/コース版を確認して匿名開始を同じタブへ保存し、既存の開始記録を引き継ぐ。不正/別版記録は従来どおり明示置換とする。旧詳細URLはコマ画面へリダイレクトし、先の訪問地点一覧を表示しない。

コマ画面は地図・番号・前後操作・見方ボタンを中心にする。ヘッダー/コースタイトル・訪問地点一覧・開始日時・次区間/累積距離は常時表示しない。凡例/安全案内・レイヤー/番号選択と出典時点は開いたときに確認する。OSM帰属は画面に残す。左右スワイプ/キーボード移動を使えるようにする。

該当コマだけにチェックポイント名と撮影案内を出す。先の名称は移動選択肢に出さず、OSM目印の表示名も登録名称に一致する部分を伏せる。コース名/開始・終了名に含まれる登録CP名も参加者向けの表示で伏せる。保存済みの名称・図形/距離は変更せず、運営者には元の名称/距離を表示する。

これは表示上の先出しを避ける方針。データの暗号化や別名/自由記述からの推測の防止、手で先のコマへ進むことの防止ではない。該当コマに進んだことを現地到着の証拠にしない。

## 保持する境界

公開停止/同じ内容の再公開の[ADR-019](019-course-publication-controls.md)を継続する。新しい画面/開始前は公開状態を再確認し、停止中にコマを配信せず、既存のタブ内開始記録を保持する。

SQLite v7・保存済み形式v1・開始形式v3は変更しない。写真や新しい進捗DBを追加しない。生成器・歩行条件・OSM固定データ/距離の計算、元の角度/全枝・進入退出と近接分岐の拡大方式も変えない。

旧固定デモのURL・画像出典・開始/達成/終了記録の検証コードは開発履歴として保持し、通常の参加者一覧から旧デモへのリンクを外す。旧機能を新しいMVPの未達として扱わない。AWS/一般向け配信・現地/実機の検証は独立した後続。今回の実装・検証/レビュー・コミット後に停止する。
