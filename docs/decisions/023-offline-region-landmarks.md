# ADR-023：Mapillaryを開発PCの地域バッチへ集約する

2026-11-12。採用済み。ユーザーが全地域の事前取得・重複排除・128×128切り抜きと公開アプリの外部取得禁止を明示承認した。

1,326分岐を開発用CLIで処理し、地物ID/座標・出典と内容ハッシュ付きPNGを配布する。Webは静的索引だけを読み、トークンの有無にかかわらずprepare/photoを拒否する。APIキャッシュと採否記録を分け、元の街路写真は公開物へ入れない。OSM背景タイルは継続する。

Sharp 0.35.5は既存導入版を開発用直接依存として明示する。AWS固有SDKやジョブ基盤は追加しない。128px化を識別精度の保証とせず、撮影日・現地/進入方向の確認を残す。

[仕様・検証](../region-landmarks.md)。ADR-021/022のアプリ内取得を置き換え、写真の初期不採用/階段必須と保存版固定を継続する。通常公開版への写真統合・現地/実機・AWSは後続。
