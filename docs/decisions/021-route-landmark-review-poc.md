# ADR-021: ルート単位の目印準備と運営者の採用判断（PoC）

- 日付: 2026-11-12
- 状態: ユーザー承認に基づくPoC実装。通常の公開/参加者への統合は後続
- 根拠: ルート決定後の交差点取得案への承認、一時停止/横断歩道の初期採用、その他初期不採用と全候補の運営選択、設定済みトークンで成果まで検証する明示依頼

## 決定

ルートと道路コマは従来どおりローカルで先に計算する。そのルートが使う地点/進入方向を整理し、未取得地点だけを非同期でMapillaryから準備する。地物の推定座標を使い、カメラ座標を対象物位置とみなさない。画像と検出領域は運営者が確認する候補だけ追加取得し、再閲覧では保存済みを使う。

記録のある止まれ・一時停止点・横断箇所を初期採用し、信号/固有看板等を初期不採用とする。全候補は運営者が変更できる。記録の種類と確かさを区別し、停止点から標識の現物や横断箇所から塗装形状を補作しない。旧PoCの個数上限で採用候補を落とさず、配置できないものは採用状態を保って明示する。

小範囲のPoC専用ファイル保存を既存SQLiteと分け、容量/件数/再利用期間と競合/ルートの版を制限する。外部SDK/認識モデルや永続ジョブ基盤は追加せず、既存の検出領域をCanvasで切り出す。画像/出典はローカル検証用とし、既存の保存済み/公開版を変更しない。

## 影響・未決定

選択をルート/コマごとに保存でき、同じ地物の取得を再訪/別コースで再利用できる。位置や現物/進入方向からの可視性は未確認で、画像品質条件だけで現地の識別性を保証しない。OSM/Mapillaryの重複、別写真/配置修正、公開版の画像参照/出典の固定、更新/失効・長期保持と一般配信条件は後続。
