# ADR-006：両チェックポイント達成と最後のコマのボタンでデモ終了を記録する

- 日付：2026-11-08
- 状態：承認済み。ユーザーが「A：両地点達成＋最後のコマでボタン（推奨）」を選択。
- 対象：P3-05の固定ローカルデモ。実際の到着確認・QR・クーポンは含まない。
- 関連：[ADR-005](005-demo-checkpoint-recording.md)、[バックログ](../backlog.md)、[参加者画面](../participant-app.md)

## 決定

海南神社C1・本瑞寺C2の両方をデモ達成として記録した後、最後のコマG（三崎港周辺）にある「デモ用：ゴールする」を押すと終了を保存する。W1は必要達成数に含めない。両地点の達成や最後のコマの閲覧だけでは自動終了しない。

終了にはstopId・method（demo-button）・recordedAtを保存し、同じ参加への再処理では最初の終了日時を保つ。保存の読戻しまで確認してから終了表示とする。未達成・別コース版・別参加・対象違い・不正な時刻・保存失敗は終了成功としない。

保存形式v3にcompletionを追加する。v1/v2は参加ID・開始日時・既存達成を保ち、終了記録なしとして読む。閲覧だけでは保存し直さず、次の明示操作でv3を保存する。コースの内容版とタブ内保持の範囲は変えない。

終了後もコマ・写真と終了結果を閲覧できる。再読込みでは閲覧位置を先頭へ戻すが終了日時は保持し、ゴール結果へ移動できるようにする。達成・終了をやり直す操作や新しい参加の自動発行は追加しない。

## 理由・残課題

両地点で自動終了する案と比較し、コース終端での明示操作を残すと、デモの開始・達成・終了を分けて検証できる。

これはボタンによる開発用の終了記録で、実際の到着や歩行、本人確認を証明しない。記録は変更・消去可能なブラウザ内データ。QRはP3-04b、クーポンの内容/条件/再発行はP3-06で別途確認する。AWS・DB・クラウドSDKは導入しない。
