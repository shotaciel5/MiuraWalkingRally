# ADR-018：保存済みコースを固定版として参加者へ公開する

- 日付：2026-11-10
- 状態：ユーザーが「A：公開→開始→コマ閲覧まで（推奨）」を明示承認。P4-06eとして実装・検証済み。
- 関連：[採用仕様](../publication-plan.md)、[開発順ADR-017](017-published-participant-priority.md)、[保存ADR-016](016-saved-course-snapshots.md)、[表示ADR-015](015-operator-koma-expansion.md)。

## 決定

運営者が保存済み詳細で対象名と保存版を確認し、明示操作で参加者一覧へ掲載する。保存だけでは公開しない。既存コースを自動掲載しない。同じローカルアプリ内の公開状態であり、AWS・外部へのデプロイや一般参加受付の開始を意味しない。

公開対象は保存済みIDと内容指紋に固定し、公開日時とともに既存SQLiteの別表course_publicationsへ保存する。SQLite v5→v6で台帳・削除・下書き・補正・保存済みを保持する。保存モデル形式v1は変更しない。同じ公開要求の再送/同時実行は、元のID・指紋・公開日時を返す。クライアントが計算結果や公開日時を指定する方式は採用しない。

参加者の一覧→詳細→明示開始→そのコースの全コマ閲覧をつなぐ。公開していないID・不明/不正IDは参加者側で利用できない。公開情報や対象の破損/不整合は失敗として表示し、未掲載0件や別コースへの差替として隠さない。

参加者へ渡す値は保存時の概要、地点/役割/説明、コマ・局所補足情報と参照形状だけとする。現在の台帳/道路/生成器を閲覧時に使わず、下書き条件や全道路グラフ、運営者の確認・修正UIを渡さない。後の台帳変更やスポット削除で公開版を変えない。

## 開始と表示

匿名・個人情報入力なしの既存sessionStorage形式v3を再利用する。コースIDごとにキーを分け、版には保存指紋を含める。同じコース/版の再操作・再読込みは参加ID/開始日時を保持する。不正/別版記録を自動上書きせず、利用者の明示的な新規開始を必要とする。保存拒否や読戻し失敗を開始成功とせず、再確認できるようにする。

チェックポイント0件も開始できる。開始/終了が同じ施設でも役割と通過を分け、再訪・全コマを保持する。コマ選択は閲覧であり、到着/達成/ゴールを記録しない。閲覧位置は保存しない。

ADR-015の拡大図＋周辺30m参照図を、新しい可変コースの参加者コマ画面へ適用する。元の角度・局所形状・全枝/進入退出・道路沿い距離・目印を保持し、未知/読みにくい図は引き続き保留する。生成や倍率計算は変更しない。固定デモの既存URL、31コマ、参考写真、開始/達成/ゴール/記録は保持し、一覧に別の検証用リンクを置く。

## 境界と後続

現地の入口/通行/安全性は未確認のまま表示し、公開操作を安全確認済みの証明としない。OSM帰属と出典時点を表示する。UI/API/repositoryを分け、ローカルOrigin/JSON/no-storeと小さい要求の制約を継続する。認証は追加せず、画面切替を認可と扱わない。

可変コースの達成/ゴール条件、掲載解除/更新と開始済み利用者の扱い、確認履歴、QR/クーポン、端末間/長期保存、一般向けの配信・権限・AWS保存先は今回含めない。掲載解除/差替がまだできないことを公開確認時にも表示する。今後の採用判断は個別に承認を受ける。
