# ADR-015：運営者プレビューの短い枝を拡大し30m参照図を残す

- 日付：2026-11-09
- 状態：ユーザーが「A：30m参照図＋自動拡大図（推奨）」を明示承認。P4-04cとして実装。
- 対象：運営者の生成プレビューのみ。[ADR-003](003-koma-presentation.md)の短い枝を保留する方針に対する限定的な表示上の例外。
- 関連：[比較・承認範囲](../koma-presentation-options.md)、[実装・検証記録14節](../operator-app.md#p4-04c)。

## 決定

短い進入/退出の枝だけが原因で保留になったコマについて、検証済みの元形状を保持し、画面の実表示幅に合わせた拡大図と周辺30mの参照図を用意する。元の角度・局所形状・全枝・進入基準と、開始/終了/折返しの役割、コマ数・訪問順・次のコマまでの道路沿い距離を保つ。分岐の追加/省略/統合や道路の延長を行わない。

通常コマ、参加者側、固定PoCは従来の表示を使う。既存の標識・施設記号を再利用する。道路と同じ倍率で建物/目印を投影し、階段は拡大後の道路の元線分と同じ区間から描く。見切れる情報は30m参照図と周辺の目印一覧へ残す。参照図は道路と周辺情報の確認用で、短い枝へ進入点/矢印を置かない。

## 適用と保留

元の道路参照・全枝・方向がそろってから短い枝を判定し、運営者の生成だけが参照形状の保持へopt inする。通常の生成関数の既定動作と、元の30m図のheld状態/理由を保つ。保存結果や現地確認済みフラグを追加しない。

クライアントで実表示幅を測定し、最短選択枝が画面上約36pxになるよう同倍率で拡大する。図上の元点列の前方部分を切り出し、元線分のID/割合を保つ。比較時の約10倍は図幅300pxの場合の値で、狭い表示幅ではさらに拡大する場合がある。拡大中の表示と30m参照図を併用し、周辺情報を失ったと判断させない。

表示幅が小さすぎる、方向不明/欠落/不整合、記号と別枝または進入/退出記号同士が近すぎる等の場合は拡大図を採用せず、保留を継続する。現在の実装では幅160px未満、他枝まで12px未満、進入/退出記号の間隔14px未満等を保守的な描画条件として確認する。これらは図の記号配置の条件で、地理的精度・実際の通行や安全性の基準ではない。

## 保存・限界

表示幅・拡大率・参照図の開閉は画面内だけで保持し、下書き/補正やDB形式v4、道路データを更新しない。歩行ルールを緩和せず、候補/保留/除外と現地未確認の扱いを継続する。コマが描けることと、安全な入口/通路を確認したことを区別する。

実端末/現地での読解、未知形状/全折返しの網羅、目的地アクセスやゲート・未接続地点の採否は後続。生成結果保存/公開、参加者側への適用、AWSは今回進めない。

## 2026-11-10：短い折返しの倍率計算の修正

P4-04dで、同じ枝が進入/退出となる場合は、元の黒点/矢印端の間隔を画面上16pxへ拡大する倍率も計算する。従来の約36pxの枝長だけでは14pxの記号間条件を満たせないため。切出し後の14px/他枝12px/枝長30px等の判定を維持し、幅や形状のため読めない場合は保留する。元形状/枝を同倍率で扱い、30m参照・距離/コマ数・保存値/参加者を保持する。承認済みの表示条件を満たすための実装修正。[原因・検証](../short-return-koma-fix.md)を参照。

## 2026-11-10：公開した可変コースの参加者画面へ適用

ユーザーがP4-06eのA案を承認したため、新しい公開可変コースの参加者コマ画面へ、同じ拡大図＋30m参照図を適用する。[ADR-018](018-published-participant-courses.md)を参照。上記「運営者のみ」「参加者側は従来」は当初の適用範囲の記録で、この承認範囲を追加する。

既存の表示コンポーネント/形状・全枝/進入退出/距離・目印と保留条件を再利用する。生成/倍率の新方式は追加しない。固定デモの31コマ/写真/進行と固定PoCは従来どおり保持する。
