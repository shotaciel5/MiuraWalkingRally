# ADR-003：PoCのコマ図の向き・枝・距離表示

- 日付：2026-11-06
- 状態：承認済み。実データの比較図を提示し、ユーザーが「A案：進入方向を基準にする（推奨）」を選択した。
- 対象：P2-06のローカルPoC。公開安全性・現地確認・本番サービスの完成承認ではない。

## 決定

入ってきた道が下になる向きでコマを表示する。開始は進入方向がないため退出方向を上にし、終了は進入のみを描く。折返しでは同じ枝へ戻る矢印と説明を示し、新しい退出路を作らない。

P2-05の全候補を省略・統合せず、通過順に並べる。元の枝の角度と局所形状を保持し、直角・等間隔の道路へ置き換えない。距離は、その通過位置から次のコマまでの道路沿い累積距離を表示する。到着点には対応するスポット名・役割を示す。

既存のSVG描画を再利用し、新しい地図ライブラリを追加しない。各枝は便宜上30m以内、次の分岐・終端までを切り出し、元の点列を回転・投影して描く。切出し長は描画範囲であり、精度の許容値ではない。角度・距離の精度閾値は引き続き未決定。

方向不明・欠落・分岐不整合を推測で補わない。矢印と進入の記号を区別できない短い枝もコマの確認待ちとして残し、不完全な交差点を完成図に見せない。徒歩通行の候補・除外・保留は表示し、現地の安全確認済みとはしない。

## 理由と残課題

進入方向を基準にすると、読んだときの左右と進む枝を対応させやすい。省略を加えず検証し、実道路の枝や往復を消さないことを先に確認する。コマを減らす粒度、近接分岐の統合、複雑な交差点の表現は、今回の結果を見て別途検討する。

比較案B（北を上に固定）は今回採用しない。方位角・元道路の根拠は引き続き全体地図と詳細で確認できる。施設写真・利用条件、実際の入口、通行規制、現地での読解・安全性は未確認を継続する。
