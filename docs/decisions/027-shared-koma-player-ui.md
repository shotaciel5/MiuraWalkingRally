# ADR-027：共有版の参加者UIと独立したテーマ設定を採用する

- 日付：2026-11-13
- 状態：ユーザーのUI採用指示に基づき実装。キャラクターの配信/再配布許諾は未確認。
- 根拠：「共同開発者がコマ地図のUIを考えてくれたからそれを採用して実装」

共有版の12テーマ・キャラクター/装飾・前後操作と独立した画面/地図設定を、現在の公開コースへ移植する。原本の固定コース・Reactバンドル・iframeや疑似端末枠は使わない。運営者の目印採否/③による省略と保存/公開モデルは維持する。

テーマは共有版と同じlocalStorageの2キーで保持する表示設定とする。参加記録のsessionStorageやコース/目印保存と分離し、既知の値だけ復元する。利用不可でも移動を妨げない。装飾は任意のReactNodeとしてSVG背景より上/本当の地物より下に置き、形状計算に入力しない。

提供画像は抽出した原本のままローカルへ同梱し、既存Next.js Imageで表示する。出典と許諾未確認を記録する。原資料/公式案内の条件から、一般公開を許可された素材として扱わない。追加依存/外部API・AWS操作・再学習は含めない。[仕様・検証](../koma-ui-integration.md)。
