# ADR-019：公開停止後は次回読込から閲覧を止め、同じ版を再公開できるようにする

- 日付：2026-11-10
- 状態：ユーザーが「A：次回読込から全員の閲覧を停止（推奨）」を明示承認。P4-06f-2として実装・検証済み。
- 関連：[仕様と比較](../course-publication-lifecycle.md)、[固定版の公開ADR-018](018-published-participant-courses.md)、[運営画面22節](../operator-app.md#publication-controls)。

## 決定

運営者が保存済み詳細で対象名と影響を確認し、公開停止/同じ内容の再公開を明示操作する。停止時は参加者一覧から外し、新規開始・開始済みの人とも、次のサーバー読込から詳細/コマを開けなくする。保存済みコースとタブ内の開始記録を消さない。同じ保存ID/指紋を再公開すると、同じタブに残る参加ID/開始日時を引き継ぐ。

コースは選んだスポット/経由地・訪問順から作成した固定の内容。公開の切替で再生成や差替はしない。内容を変える場合は既存の下書き→再生成→確認→別保存を使い、新コースの公開と旧コースの停止をそれぞれ明示実行する。差替専用機能・参加記録の別コースへの移行は追加しない。

## 保存と再送

SQLite v6→v7で既存の台帳編集/削除・下書き/補正・保存済み/公開情報を保持する。既存の公開行は公開中/変更版1として、元の公開日時を引き継ぐ。未掲載コースは自動公開しない。保存済み形式v1と開始記録形式v3は維持する。

公開状態（公開中/公開停止）、変更版、直近の操作日時を保持する。コース内容の指紋と公開状態の変更版は別に扱う。公開時の日時は直近の公開日時で、再公開時に更新し、同じ操作の再送では元の日時を返す。

対象ID/指紋と読み取った状態の変更版を照合して更新する。同じ操作の再送・同時実行は同じ結果を返す。停止→再公開後の古い停止要求や、停止後の古い公開要求で状態を巻き戻さない。競合時は開き直して再確認し、公開情報を削除して未掲載へ戻す方式は使わない。旧画面から版を持たない変更要求も受け付けない。

## 参加者への適用

停止したURLは一般的な停止案内を表示し、コース名/コマを配信しない。不明/未掲載は従来どおり404、破損/読取失敗は利用不可として区別し、記録を初期化しない。

参加者の新しい画面表示と開始/再開操作では、no-storeの小さい状態確認を行う。公開中かつ保存したコース版が一致するときだけ開始保存/表示へ進む。読取失敗や停止を開始成功と扱わず、再確認できる。開始記録をサーバーへ送ったり、参加者の認証/権限に使ったりしない。ブラウザ履歴から復元された画面もpageshowで再確認する。

すでに読み込まれた図や画像を遠隔回収せず、コマ操作ごとの常時照会・自動通知は追加しない。開いたままのコマ画面は再読込まで残り得る。状態確認直後の他操作や発行済み応答を含め、即時に全端末を無効化する仕組みではない。

## 境界

UI/API/repositoryを分離し、既存の同一Origin/JSON・小さい要求/no-storeを継続する。新しい依存・認証/認可・クラウドSDKは追加しない。現地の入口/通行/安全性は未確認のまま。作成したコースの達成/ゴール、QR/特典・確認履歴・一般受付/外部配信・AWSは後続。今回の実装/検証・レビュー・コミット後に停止する。
