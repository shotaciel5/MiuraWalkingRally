「？」の中に画面と地図の選択を置き、地図は「画面に合わせる」を標準とする。選択は同じブラウザのlocalStorageへ、共有版と同じ2キー（miura-walk-design-v1、miura-map-design-v1）で保持する。既知の値だけを復元し、不正値/読取不可は既定へ戻す。書込不可でも画面の選択と移動は続け、設定内で保存できなかったことを案内する。参加記録・コースや採否の保存は別の既存処理を維持する。タブ間の即時同期・アカウントへの保存は追加しない。

前後ボタンは移動に専念し、最初/最後では該当ボタンを無効にする。コース一覧への出口は上部とゴール案内に置く。スワイプ・左右キー・番号指定・設定/参照図を継続し、動きを減らす設定も尊重する。端末を模した固定393×852の枠はアプリへ持ち込まず、実ブラウザ幅と縦スクロールに対応する。

## 現行アプリとの境界

- 道路の点列/角度/枝/進行方向、③の省略、短い枝の拡大と30m参照図、距離計算・CP位置は変更しない。
- KomaFigureの背景直後に任意の装飾ReactNodeを置く。装飾はaria-hidden/pointer-events:noneで、道路・階段・採用目印/写真より後ろへ描く。運営者の図には渡さない。
- スクリーンのテーマと地図のパレットを属性/CSS変数で分ける。黒い進入点/青い矢印、停止・横断等の交通記号の色は維持する。テーマの灯台/魚/花等は実際の地物の位置や道順を表さない。
- 通常の採用目印/128px写真・階段必須、建物形状/名称を出さない方針と、先のCP名を伏せて到着コマで撮影を促す方針を継続する。共有版の古い建物/施設名レイヤーへ戻さない。
- 保存形式・公開状態・sessionStorageの匿名開始記録を変えず、保存済み版を再生成しない。旧v1/v2/v3と新しい省略版の表示を共通UIで扱う。

## 実装と提供物

- app/published-navigator.tsx：現在の公開コースと共有UIの接続。
- app/walk-design-controls.tsx、lib/participant-design.ts：設定UI/ホワイトリスト/独立した保存境界。
- app/walk-theme-art.tsx：共有版の独自SVG/装飾32部品をReact/TypeScriptへ移したもの。ライブラリのバンドルは複製しない。
- app/walk-design.css：参加者向けのレイアウト/テーマだけを抽出。運営/トップの配色を置き換えない。
- data/ui/walk-themes.json、koma-ui-provenance.json：元の12定義・入力HTMLのSHA・提供画像のSHA/サイズを記録。
- public/characters：提供HTMLに埋め込まれていたJPEG2枚と切り抜きPNG1枚を無加工で抽出。表示には既存Next.js Imageを使う。

元のkoma-ui-shareはユーザー提供物としてそのまま保持し、変更/移動/上書きしない。巨大な単体HTMLや同梱の固定コースをアプリの実行/ビルドへ要求しない。原本は今回のGitコミットへ追加せず、統合ソース・出典/指紋・必要な素材だけを対象とする。
