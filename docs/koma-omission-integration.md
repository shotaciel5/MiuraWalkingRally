# 道なりによるコマ省略の統合（P4-08）

ユーザーの依頼に基づき、共同開発者の引き継ぎ一式を通常の生成・確認・保存・公開へ統合する。通常は道なり省略版を表示し、「省略設定」から全交差点表示に一括切替できるようにする。個別の省略チェックボックスを通常画面に並べない。

## 受領物と配置

元のkoma-omission-handoffはtools/koma-omission-referenceへ内容を変えず移動する。93ファイルの配布ハッシュと元ソース/評価データ/モデル/テストを保持する。アプリが使う元ルールの最小コピーはlib/route/omission/vendor/routing.cjs、型・互換解析・選別/投影は同ディレクトリのTypeScriptへ分離。コピーしたルール本体のSHA-256を参照ソースと照合する。参照用target-referenceを本体へ上書きしない。旧対象21adcfebから現行6791570への差分は、目印採否・保存版v2・選択中枠UIを保つアダプターで吸収する。

付属AIは独立評価前の候補であり、今回は検証可能な既存ルールを標準に使う。AI推論・Pythonサービス・外部API/新依存は実行時へ加えない。モデル/350特徴量/旧OOFのgolden検証は受領資料のテストで保持する。旧再集計の1.5%をこのアプリの精度として表示しない。

## 選別と形状

全候補の抽出と従来の30m描画を保つ。別途、元道路のWGS84枝を最大28m・次の実分岐までたどり、直前のCP/折り返しを越えない実経路の8m手前から進入方位を求める。SVG座標/端点から進入路を逆算しない。

互換グラフは形状用で、既存の徒歩経路グラフを置き換えない。枝集合の相違・28m内のトポロジー差、未知の枝端/進入路、held/確認事項は保持。歩行可否は元ルールと既存制約の共通範囲で判断する。開始/終了/CP・経由地/折り返し・必須の右左折を保持する。60度以上の曲がりは追加で保持し、短い枝のheldも省略しない。停止等の元ルールによる保持と、直進信号だけによる保持の例外を区別する。

道なり候補→次の表示コマとの形状比較→紛らわしい候補を復帰→区間を再分割して繰り返す。直進信号だけによる保持は比較の境界にし、右左折/CP/手動編集へ例外を広げない。互換形状が読めない相手への比較も保持側へ倒す。選別した後に番号/次のコマまでの距離/CP参照/一覧/全体図を一緒に再計算する。経路の距離と全候補の安定IDは保持する。

明示した目印編集のある元コマも保持する。再番号と採否キーを混同せず、採用状態は従来の全候補側の番号に対応付ける。

## UIと保存

通常プレビューは省略モード。設定ボタンを押したときにだけ、省略/全交差点の選択と枚数を表示する。設定はコース保存に含める。保存済み詳細の切替は確認用で、公開内容を変えない。元の採用写真・階段・候補一覧のスクロール・図上採否操作を維持する。

新規保存はpayload v3とし、全候補/目印・省略アルゴリズム版/判定情報・手動保護・表示対象・選択モードを固定する。判定情報には将来の比較対象との類似関係を持たせ、手動保護後も同じ反復選別を再現する。クライアントから全生成モデルを受け付けず、サーバーでモード別receiptを再照合する。保存後は現在の道路・ルール・採否を読み直して変えない。

旧v1/v2や同梱デモを自動更新せず、旧版は全コマのまま読む。新しい省略版が必要なら再生成・別保存する。参加者には保存した表示対象だけを渡し、CP名の表示条件・距離非表示・開始記録を維持する。SQLite v7・既存公開停止/再公開は変更しない。

## 検証と制限

受領時のハッシュ93件・Node40件成功。PythonはWindows既定文字コードで失敗したためPYTHONUTF8=1で再実行し、元資料を変更せず15+4件成功。golden12ペア/350特徴量・697問の旧OOFスコアを含む。Pythonは検証専用で、アプリ起動に不要。

移植後は元選別との一致、必須地点/不明データ/手動保護、再採番・距離/CP、保存/再送/公開と旧版互換、型/ビルドと画面操作を検証する。現地/実機・独立評価・AWSは未実施。資料のコードに新たな公開ライセンスを付けず、出典・権利上の注意を保持する。一般再配布の条件は各権利者との確認事項として残す。

このタスクの自己レビュー・コミット後に停止し、mainへのマージ・push・デプロイは実行しない。
