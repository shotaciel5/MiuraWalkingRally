# 地点指定と訪問順の反映を見やすくする（P4-12b）

2026-11-15。ユーザーの追加依頼に基づく運営者の地点選択画面の調整。

## 表示と操作

- PCでは候補一覧220px、訪問順420〜480pxを確保し、中央の地図を従来より狭める。訪問順の見出し・コース名・変更通知・保存ボタンをパネル内で固定し、訪問地点の部分だけスクロールする。
- 地図・一覧で選んだスポットと、その用途を指定する4つのボタンは地図の下へ配置する。右側は訪問順を確認して並べ替える場所として独立させる。
- スタート/ゴールのS/Gと途中地点の通過番号を縦に並べ、地点名に同じカテゴリの絵アイコンを添える。地点名を押すと地図の下へその地点の設定ボタンを表示する。
- 用途を指定した直後に、右の該当行へスクロールし、背景色・枠線と「○○をスタートに設定しました」「チェックポイントに追加しました」等の通知を表示する。同じ地点を繰り返し指定しても反映先を見せる。
- 設定ボタンにはチェックと「設定済み」、候補一覧には指定済みの役割を表示する。開始と終了が同一なら両方を示す。
- 途中地点の「↑前へ」「↓次へ」で訪問順を変更し、移動先を通知する。役割変更と削除にも通知を付ける。従来どおり途中地点の重複は追加できず、役割は訪問順の選択欄で変更する。
- 「設定しました」は画面内の下書きへの反映を示す。「未保存／保存済み」を別に表示し、明示保存に成功した時だけ保存済みへ変更する。保存中はコース名も編集できない。
- 候補の初期接続状態、位置情報、使い方、道路調整の説明は詳細へ整理する。台帳の変更・削除・補正の不整合やAPI失敗は従来どおり表示する。
- 小画面は縦配置。短い強調アニメーションは動きを抑える設定では止め、色・枠線・通知で反映を伝える。

## 維持する条件

訪問順、スポットのスナップショット、明示保存、競合検査、未保存の離脱警告、到達点補正、生成可能条件を維持する。新しい永続化・API・依存・AWS操作は追加しない。施設の選択は、入口・道路・現地安全性の確認を意味しない。参加者の画面と公開済みの内容は変更しない。
