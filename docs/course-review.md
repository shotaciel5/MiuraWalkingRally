## 1. 今回の一つの価値

保存済み詳細の「確認する箇所」から、見直すコマへ少ない操作で移る。既存の訪問順/候補・全体地図・コマ一覧と組み合わせ、入口や図形に残る注意を探しやすくする。

保存形式v1にある事実だけを集約する。現在の台帳/道路の照合、生成や外部取得を呼ばない。人による確認状態・安全性・公開可否を計算しない。現地未確認の表示と、保存内容の不変性を維持する。重要な選定や承認済み方針の変更がないため、新しいADRは追加しない。

## 2. 件数と該当コマ

| 表示 | 保存値からの根拠 | 案内 |
| --- | --- | --- |
| 施設と道路上の到達点 | 訪問のspotIdの異なり数と訪問数。開始/終了の共用も訪問数には両方残す。 | 既存の「訪問順と道路への候補」へ移り、全施設と道路上の候補を確認する。距離の閾値で問題なしと判定しない。 |
| 図の確認待ち | mapがheldで、短い枝の参照形状を持たないコマ。 | 元データ・方向・形状の根拠を見る。 |
| 近接分岐・拡大確認 | 保存されたshortGeometryを持つコマ。 | 実表示幅に応じた拡大図と30m参照図の両方を見る。拡大の数値条件を安全確認と扱わない。 |
| 保留・対象外の枝を含む | candidate.branchesのentryまたはexitにreview/excludedを含むコマ。 | 交差点の枝ごとの状態を確認。候補に使わない枝も描く既存方針を保つ。 |

図が描けるコマにも保留の枝があり得る。進入/退出の両方を見る。同じコマに複数の注意があっても一覧では1行にまとめ、注意の種類をすべて表示する。各カテゴリの件数は重なりがあり、単純合計を該当コマ数にしない。同じ地点の再訪は別コマとして通過順に残す。

既知のカテゴリに入らないcandidateのissuesや描画可能なmapのissuesも「元データ・図の注意」として案内する。選択後の「形状・出典・確認事項」には保存済みの元注意を重複なく表示する。保存時の注意文字列は文字列として描画する。

## 3. 操作と空状態

「該当コマを見る」を開き、コマ番号と注意を選ぶと既存の選択コマ・地図・一覧を同期する。選択コマ見出しへスクロールし、フォーカスも移す。マウス/キーボードで使え、注意の行を省略しない。1280/390/320pxを確認する。

注意が0件のカテゴリも0を表示する。全件0でも「上記の注意を持つコマはありません。全コマと到達点の確認を続けてください」と案内する。自動抽出の注意がないことは、現地確認や公開準備の完了を意味しない。

未保存プレビュー・固定PoC・参加者にはこのパネルを追加しない。保存済み詳細に確認済みボタンや公開ボタンは置かない。閲覧・選択でSQLiteや保存JSON、確認日時/進捗を書き換えない。新API・DB移行・依存・外部通信は不要。

## 5. 公開へ進む前に残る判断

| 論点 | 今回の扱い |
| --- | --- |
| 現地確認の範囲・方法、確認の記録 | 未決定。入口/施設までの通路・横断/通行/安全性、全コマの読解などを人が確認する要件を維持。自動件数で置き換えない。 |
| 保留コマ/枝の注意の解決条件 | 未決定。拡大表示や対象外枝の存在だけで一律に公開可/不可と決めない。実際に進む道と分岐の読解を確認する必要がある。 |

| 配信範囲・権限と運用 | 未決定。画面切替を認証/認可と扱わず、ローカル用APIをそのまま外部公開しない。Cognitoの採用は前提にしない。 |

次のP4-06dは、確認結果として何を記録し、どの条件で公開へ進めるかを必要な深さで比較・承認する仕様タスクの候補。今回は人の確認記録を先に実装・確定しない。未接続15地点の扱いは独立した候補として残す。

## 6. 検証と停止

集約の入力非更新・保存値だけによる決定性、施設数/訪問数、重複する注意/再訪、進入/退出、図の保留/拡大、未知の注意/0件を自動テストする。ブラウザは各カテゴリと対象選択/地図の同期・キーボード/フォーカス・3画面幅・DB非更新を確認し、既存の保存/再試行と参加者表示の回帰を確認する。

今回の実装・検証・自己レビュー・コミット後に停止する。新しい確認記録/公開仕様の採用、実公開・参加者追加開発・AWSは人間の次の指示と必要な承認を受ける。最終結果は運営画面17節へ記録する。
